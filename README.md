# TMPOS Desktop

![Version](https://img.shields.io/badge/version-2.12.13-blue)
![Downloads](https://img.shields.io/github/downloads/tmpos/tmpos-desktop/v2.12.13/total)

Sistema de punto de venta e inventario offline para tiendas, con sincronizacion mediante TMCloud.

## Novedades v2.12.13

- **Corrige un crash critico al iniciar la app** por una columna faltante en la tabla usuarios.
- Al registrar o cambiar de licencia, se limpian los productos locales con el autoincremental reseteado.
- Corrige el orden de descarga en sistemas nuevos para que IMEI y telefonos queden conectados desde la primera sincronizacion, con reparacion automatica para instalaciones ya afectadas.
- Nueva ruta de la base de datos visible (con boton de copiar) en Configuracion > Soporte.
