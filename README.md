## Descargar TMPOS para Windows

[![Descargar TMPOS v2.12.15](https://img.shields.io/badge/Descargar_TMPOS-v2.12.15-16a34a?style=for-the-badge&logo=windows)](https://github.com/tmpos/tmpos-desktop/releases/download/v2.12.15/TMPOS.Setup.2.12.15.exe)

El instalador es compatible con Windows 10 y Windows 11 de 64 bits. Los datos existentes se conservan durante la actualización.

## Novedades de v2.12.15

- Mejoras de estabilidad, enfoque y navegación en la interfaz.
- Refuerzo de la sincronización con TMCloud y el trabajo offline.
- Mejoras en facturación, inventario, IMEI, taller y financiamientos.
- Ajustes en configuración, soporte y asistente inteligente.
- Correcciones generales de rendimiento y experiencia de usuario.

## Actualización

1. Descarga `TMPOS.Setup.2.12.15.exe`.
2. Cierra TMPOS si está abierto.
3. Ejecuta el instalador y conserva la ubicación actual.
4. Abre TMPOS normalmente; tus datos locales permanecerán disponibles.

Consulta todos los archivos y notas en la página del [release v2.12.15](https://github.com/tmpos/tmpos-desktop/releases/tag/v2.12.15).
