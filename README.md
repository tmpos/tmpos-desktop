# TMPOS Desktop

![Version](https://img.shields.io/badge/version-2.12.12-blue)
![Downloads](https://img.shields.io/github/downloads/tmpos/tmpos-desktop/v2.12.12/total)

Sistema de punto de venta e inventario offline para tiendas, con sincronizacion mediante TMCloud.

## Novedades v2.12.12

- Corrige el falso positivo de "registros actualizados" causado por columnas legado que ya no existen en el servidor.
- Evita avanzar el watermark de subida de una tabla si la subida tuvo errores, para reintentar esas filas.
- Refresco automatico por componente cuando llegan cambios de sincronizacion, con aviso, sin recargar toda la app.
- Efecto hover mas claro en el dialogo "Reubicar en otro telefono" de IMEI.
- Nuevo asistente Jarvis (OpenAI) y modulo de financiamiento.
