Sistema de punto de venta e inventario offline para tiendas, con sincronizacion mediante TMCloud.

## Novedades v2.12.9

- Nueva vista de registro de licencia con validacion en servidor y configuracion automatica de TM Cloud.
- Sincronizacion de datos de empresa desde la nube al registrar licencia.
- Soporte para secret_key de TM Cloud en la respuesta del backend.
- Correcciones y mejoras en el flujo de activacion de equipos.
